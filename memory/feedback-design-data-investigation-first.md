# Feedback：设计前先做线上真实数据调研

> 来源：OMMUSIC-3593553（LRC 翻译歌词自动识别拆分）踩坑复盘的沉淀。

## 触发

凡是为用户**设计技术方案 / 敲定需求识别规则（识别/解析/分类/归一化/兜底阈值）**之前，必须先基于**线上真实数据**调研，再定方案、再编码。所有需求一律强制，不分类。

## 铁律

1. 顺序不可颠倒：先数据调研 → 再定规则 → 再设计 → 再编码。
2. 核心判定假设必须用真实数据验证，不臆想。
3. 自测通过 ≠ 方案正确（自测样例是构造的，凑不齐真实脏数据）。
4. 边界/兜底/阈值决策必须由真实数据量化佐证。
5. 调研结论落到设计文档，能回答「误伤多少」。
