- **选项**:
  - (a) 保持单层（按 frontmatter tag 分组）

- **日期**: 2026-06-01
- **状态**: 接受

- **选项**:

  - (b) 仅自动化 timeline.json，timeline/*.md 保留
  - (c) 反过来，timeline/*.md 才是源，JSON 从 md 生成

## ADR-004：4 个超标 kb 笔记拆分提案（2026-08-01）

- **日期**: 2026-08-01
- **状态**: 已否决（2026-08-01 用户判定 4 文件均"独立且规整"，全部不拆；2026-08-05 复查确认 热点账户/Dubbo/MySQL B+树 亦不拆）

- **规则依据**: [kb-content-style SKILL.md 拆分规则](../.claude/skills/kb-content-style/SKILL.md) —— ">1000 关注 / >1500 必须拆 / >7-8 个 ## / 覆盖 3+ 个可独立成文方向"，满足任意两条即提案。4 个文件均 >1000 行，多数同时满足"章节数超标"或"主题凝聚度超标"。

> 全局结论：4 个文件行数均 < 1500，故 **0 个"必须拆"、4 个"建议拆"**。但 Redis 与 RocketMQ 的结构违规（日期戳节夹在编号章节间）即使不拆文件也必须重组。subagents 与 Agent 开发实战则是纯"行数 + 主题凝聚度"驱动。
